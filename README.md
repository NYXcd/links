Links_V2 | Static GitHub Pages Website  

A static site exported from WordPress using LocalWP and the SimplyStatic plugin, following a similar workflow to [Fast Free Static Website with WordPress and GitHub Pages](https://www.hywel.me/static/site/wordpress/2016/07/17/fast-free-static-website-with-wordpress-and-github-pages.html)

This solution minimizes 
- tech dept
- learning curves
- hosting cost
- update time

I've written websites in raw html/css/JavaScript, experimented with modular systems like Hugo and Astro and used website builders like Squarespace and WordPress, but they did not offer the flexibility and speed I needed for small projects. 

This workflow makes a simple website with clean formatting accessible.
